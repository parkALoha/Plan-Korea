# `pending-review/` — migration ที่เขียนแล้ว แต่ **ยังไม่ให้ CLI เห็น**

ไฟล์ในโฟลเดอร์นี้เป็น SQL ที่เขียนเสร็จแล้วและ **ตั้งใจไม่วางใน `supabase/migrations/`**
