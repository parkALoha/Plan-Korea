## ⛔ กับดักที่ 2 — **stub `window.fetch` ไม่ใช่การตัดเน็ต**
การโหลดหน้า (document request) **ไม่ผ่าน `window.fetch`** → stub จับไม่ถึงเส้นทางที่ SW ทำงานอยู่
· ✅ **ดับเซิร์ฟเวอร์จริง** (`preview_stop`) แล้วค่อย reload — นั่นคือ *"เซิร์ฟเวอร์ดับสนิท"* ตามที่เกณฑ์เขียนไว้
· ✅ พิสูจน์ว่าดับจริงด้วยการยิง path ที่ SW ไม่แคช: `fetch("/api/engine/trips?__probe=…")` → ต้องได้ `unreachable`

## ⛔ กับดักที่ 3 — **แคชเก็บเฉพาะหน้าที่ *เคยเปิดตอนออนไลน์*** ⇒ ต้องอุ่นทีละหน้า
🔴 **ผมเกือบรายงานว่า `/today` พังออฟไลน์** — ของจริงคือสคริปต์อุ่นแคชของผมพาไป `/` แทน
🎯 **ตรงกับ *แดงหลอกจากสนามที่เราสร้างเอง* เป๊ะ** — และตัวที่หยุดผมคือ **ข้อความ fallback ที่บอกสาเหตุตรง ๆ**
> 📴 ยังไม่เคยเปิดหน้านี้ตอนมีเน็ต — หน้านี้ยังไม่ได้ถูกเก็บไว้ในเครื่อง …

· ✅ **ถ้ามันขึ้นแค่ "ผิดพลาด" ผมจะรายงานเป็นบั๊กแล้วมีคนไปไล่หาของที่ไม่มีอยู่**
  ⇒ **ข้อความ fallback ที่ระบุสาเหตุ ไม่ใช่ของตกแต่ง มันคือด่านกันการวินิจฉัยผิด · ห้ามลดทอน**
