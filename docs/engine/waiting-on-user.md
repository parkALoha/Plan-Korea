## 🟡 กลุ่ม 2 — ตัดสินใจ (ไม่ต้องกดอะไร แค่ตอบ)

### 2.1 ข้อความไทย hardcode — **3 จุดที่ยืนยันแล้ว** (P2 ไล่จนจบ)
```
components/CreateTripForm.tsx:124   >เริ่ม<
components/CreateTripForm.tsx:138   >สิ้นสุด<
components/HomeScreen.tsx:109       title="อ่านจำนวนสมาชิกไม่ได้…"
```
🔴 **ตัวที่สามไม่เคยอยู่ในรายการใคร** — เป็น `title=` ไม่ใช่ข้อความในเนื้อ จึงรอดสายตามาตลอด
**คำถาม:** แก้แค่ 3 จุดนี้ หรือเอา `CreateTripForm.tsx` ทั้งไฟล์ (~14 สตริงถ้านับ error/toast)
· ลำดับที่ตกลงกันแล้ว: **แก้ก่อน แล้วค่อยเปิดด่าน** ไม่ใช่เปิดด่านแดงแล้วให้คนไปปิด

เขาปฏิเสธคำสั่งของ P1 ที่บอกว่า *"commit ได้"* — **ถูกต้อง P1 ไม่มีสิทธิ์ให้**
