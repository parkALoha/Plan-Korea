# วิธีเจน+เก็บภาพปกเมือง — ฉบับที่แก้ปัญหาไฟล์ชนกันแล้ว

> 🔴 **เลิกใช้ปุ่ม "ดาวน์โหลดรูปภาพขนาดเต็ม" ของ Gemini** · เลิกใช้ `ls -t` · เลิกใช้ `diff ก่อน/หลัง` · **เลิกพึ่ง `dl-claim.sh`**
> ทั้งสามวิธีตอบคำถาม *"ไฟล์ไหนเพิ่งโผล่ใน `~/Downloads`"* ซึ่ง **ไม่ใช่คำถามที่เราต้องการคำตอบ**
> คำถามจริงคือ *"ไฟล์ไหนคือภาพจากแท็บของฉัน"* — และมันตอบไม่ได้จากโฟลเดอร์ที่ 6 เซสชันใช้ร่วมกัน

## ✅ วิธีที่ใช้ — **ให้หน้าเว็บดาวน์โหลดโดย *เราเป็นคนตั้งชื่อไฟล์***
```js
// javascript_tool บนแท็บของคุณเอง
const imgs=[...document.querySelectorAll('img')].filter(i=>i.naturalWidth>600);
const img=imgs[imgs.length-1];          // ภาพล่าสุดในแชตนี้
const a=document.createElement('a');
a.href=img.src;                          // blob: ของแท็บนี้เอง
a.download='p5-hualien.jpg';             // 🔴 ชื่อที่ "คุณ" ตั้ง — ใส่ชื่อเซสชันกันชนกันเอง
document.body.appendChild(a); a.click(); a.remove();
```
```bash
./scripts/save-cover.sh ~/Downloads/p5-hualien.jpg tw hualien
```
🎯 ***ไม่ต้องเดาว่าไฟล์ไหนของใคร เพราะชื่อไฟล์ไม่ซ้ำกับใครตั้งแต่ต้น — เอาความกำกวมออก ไม่ใช่เดาให้เก่งขึ้น***

## ⚠️ ราคาที่จ่าย และทำไมถึงยอมจ่าย
· ภาพจาก DOM กว้าง **1024** ไม่ใช่ 3584 (ปุ่มของ Gemini ให้ไฟล์ใหญ่กว่า)
· **แต่การ์ดแสดงจริงกว้าง 280px** ⇒ 1024 มากเกินพอแล้ว · `save-cover.sh` **ไม่อัปสเกล** แล้ว
· ⇒ แลกความละเอียดที่ไม่มีใครเห็น กับการกำจัดความผิดพลาดที่เห็นชัดบนหน้าเว็บ

## 🔴 สิ่งที่ยัง **ไม่** เปลี่ยน — เปิดดูภาพก่อนเก็บทุกใบ
วิธีนี้แก้ *"หยิบไฟล์ผิด"* · **มันไม่รู้ว่า AI เจนตรงเมืองไหม**
⇒ ยังต้อง `Read` ดูภาพก่อน `save-cover.sh` ทุกใบ · **ด่านนี้ไม่มีอะไรมาแทนได้**

## ข้อควรระวังอื่นที่วัดมาแล้ว
· **ปุ่มส่ง**: `find` → คลิกด้วย `ref` มักไม่ส่ง · **คลิกด้วยพิกัดได้ทุกครั้ง** (P4 · ~(828,508))
· **ช่องพิมพ์เก็บข้อความเก่า** ถ้าส่งไม่สำเร็จ ⇒ `cmd+a` → `Delete` ก่อนพิมพ์เสมอ
· **ต้องเห็นภาพบนจอก่อน** จึงกดโหลด — `find` เจอปุ่มได้ทั้งที่ภาพยังไม่ขึ้น แล้วกดแล้วไม่มีไฟล์ (P4)
· **Chrome ค้างทั้งเบราว์เซอร์** ถ้าหลายเซสชันยิงพร้อมกันหนัก ๆ (P4 เจอ 5 ครั้ง · ยังไม่พิสูจน์สาเหตุ)
